## 📝 **ROLE NAMING CONVENTION:**

All roles follow this pattern:
```
{ControllerName}{Action}
```

**Examples:**
- `CompanyMasterIndex` → View Company Master list
- `CompanyMasterCreate` → Create new Company Master
- `CompanyMasterEdit` → Edit existing Company Master
- `CompanyMasterDelete` → Delete Company Master

**For Create/Edit (Form action accepts both):**
```csharp
[Authorize(Roles = "CompanyMasterCreate,CompanyMasterEdit")]
```
This allows users with EITHER role to access the form.
